# 快速使用指南

完整逐步說明、政策與故障排除見 [入門啟用指南](入門啟用指南.md)。架構見 [系統架構](系統架構.md)。

## 需求

- Python 3.11+（建議虛擬環境）
- 或 Docker Compose

可選：OpenAI-compatible LLM（`MYCOAGENT_LLM_BASE_URL`）、本機 [OpenCode](https://opencode.ai)（`--executor opencode`）。沒有 LLM 時執行器是 Echo，demo 仍可跑。

## 安裝並起三個行程

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

# 終端 1
python -m mycoagent manager

# 終端 2
python -m mycoagent node --manager http://127.0.0.1:8080 --group default \
  --name alpha --port 9001 --advertise http://127.0.0.1:9001 \
  --skills coding --tools shell

# 終端 3
python -m mycoagent node --manager http://127.0.0.1:8080 --group default \
  --name beta --port 9002 --advertise http://127.0.0.1:9002 \
  --skills coding --tools shell
```

或一條指令：`docker compose up --build`（Manager `8080`、alpha `9001`、beta `9002`、MinIO API `9090`）。

## 發一筆任務並對照記憶

```bash
python -m mycoagent ctl catalog default
python -m mycoagent ctl submit --node http://127.0.0.1:9001 \
  --description "demo" --subtask "child work|coding"
python -m mycoagent ctl job <job_id> --node http://127.0.0.1:9001
python -m mycoagent ctl job <job_id> --node http://127.0.0.1:9002   # 預期 404
```

服務已在跑時也可：`./scripts/demo.sh`。

未帶 `--subtask` 且已設 LLM 時，父 agent 會依目錄切分子任務。未設 LLM 且未帶 `--subtask` 時，工作留在父本機用 Echo 做完。

## 一機兩個 agent

```bash
python -m mycoagent node --manager http://127.0.0.1:8080 --group default --port 9000 \
  --agent name=alpha,skills=coding,tools=shell \
  --agent name=beta,skills=coding,tools=shell
```

任務打 `http://127.0.0.1:9000/agents/<id>/jobs`。先 `GET /agents` 看 id。

## 執行器

| `--executor` | 行為 |
| --- | --- |
| `auto`（預設） | 無 `MYCOAGENT_LLM_BASE_URL` → Echo；有則內建 tool loop |
| `echo` | 固定回 `done:…` |
| `agent` | 內建 loop（需要 LLM） |
| `opencode` | 工作區內 `opencode run`（需本機已安裝） |
